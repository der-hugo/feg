# Keller Bildergalerie – Arbeitsstand 04

Zwölf Konzeptbilder, nach fünf Bereichen sortiert. Pro Bild mit „Vorher · Original“ und „Nachher · Entwurf“ vergleichen – auch in der Großansicht. Die Originalfotos sind direkt enthalten. Ein Bild anklicken, um es groß zu sehen; mit den Pfeilen oder Pfeiltasten weiterblättern. Rückmeldungen einfach anhand der Bildnummer außerhalb der Website weitergeben.

## Ansehen

Im Ordner `website` die Datei `index.html` öffnen. Die Bilddateien liegen in `website/assets` und können später auch einzeln für die Präsentation genutzt werden.

## Auf GitHub Pages veröffentlichen

1. Den Inhalt von `website` in die oberste Ebene des GitHub-Repositorys kopieren, einschließlich `assets` und der leeren Datei `.nojekyll`.
2. Committen und pushen.
3. Unter **Settings → Pages → Deploy from a branch** den Branch und **/(root)** wählen.
4. Die von GitHub angezeigte Adresse weitergeben.

Kein Build und kein Serverprogramm erforderlich. Keine Anmeldung, keine Kommentarfunktion, keine Datenübertragung durch die Galerie.

Die Bilder sind Gestaltungsentwürfe, keine maßstäbliche Ausführungsplanung oder Lichtberechnung. Einzelne Details können zwischen den Ansichten abweichen. Die finale Bildserie für PowerPoint folgt nach der Abstimmung.

`Bildbriefings.json` enthält die verwendeten Bildbriefings zur späteren Überarbeitung.
